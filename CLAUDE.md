# Bot&Cod — проєкт ботів-моніторів

Робочий простір, що об'єднує всі Telegram-боти моніторингу
органів місцевого самоврядування та декларацій.

GitHub-акаунт: `cpiodesa-prog`

## Репозиторії

### telegram-bot (Одеська міськрада)
- Двічі на день (10:00, 16:30 Київ) перевіряє `omr.gov.ua`:
  сесії ради, виконком, комісії.
- GitHub Actions → Telegram-канал.
- Окремий репозиторій: `cpiodesa-prog/telegram-bot`

### omr-monitor (RadaWatch)
- Щоденний моніторинг кількох міських рад (Одеса, Миколаїв, Херсон).
- Аналіз ризиків: ключові слова (земля, оренда, приватизація),
  порогові суми (10 млн грн), YouTube-відео засідань.
- Нове місто додається через `cities.yaml` без коду.
- GitHub Actions → Telegram (окремий чат на місто) + CSV-звіти.
- Окремий репозиторій: `cpiodesa-prog/omr-monitor`

### declaration-watcher (декларації НАЗК)
- Спостерігає за появою нових декларацій у реєстрі НАЗК.
- Два режими: за списком конкретних людей (`data/people.csv`)
  і за ЄДРПОУ установ (`data/institutions.csv`).
- GitHub Actions (кожні 6 годин) → Telegram.
- Окремий репозиторій: `cpiodesa-prog/declaration-watcher`

## Спільні патерни

- Мова: Python
- Деплоймент: GitHub Actions (cron), безкоштовно
- Сповіщення: Telegram (токен і chat_id зберігаються в GitHub Secrets)
- Стан: `state/seen.json` — комітиться після кожного запуску, запобігає дублікатам
- Усі репозиторії приватні
